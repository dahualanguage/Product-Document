做法（全部做在 v3 檔內 + 新增 styles/v3.css，未動共用 js）

  • 訂閱方案 + 管理訂單「整合為單一頁」：原 screen-orders 已刪除，Profile 只留一個入口「訂閱與帳單」（openPaywall()）。

    • Pro：方案比較表 + 「目前方案：Pro（下次扣款日）」 + 下方帳單卡（付款紀錄 / 付款方式 / 取消訂閱）。隱藏價格與「立即訂閱」，副標留空。

2 練習加入 score + 記錄作答結果 已實作

做法（fork 到 js/v3/ + styles/v3.css，未動共用檔）

註：「拼音」＝ UI 的「拼寫」練習（英文單字拼字）。最終不採星等，改為「過 / 不過」。

  • 拼寫改三次嘗試 + 漸進提示：
    • 開始時自動播放單字發音（喇叭 icon 跳動，不彈 toast；未來接 TTS）。
    • 第 1 次錯 → 提示開頭字母；第 2 次錯 → 提示所有奇數位（1,3,5,7…，如 c _ v _ l _ z…）。
    • 三次內拼對 = 通過；三次全錯 = 未通過，顯示正解跳下一題。
  • 跟讀：完成錄音即通過（demo）。
  • 結果頁：摘要「總題數 / 通過 / 未過」；作答明細依作答順序每題一列（綠勾/紅叉 + 單字 + 中譯 + 拼寫/跟讀徽章），沿用內建 .results-detail 樣式對齊。
  • 作答明細可收合、內部固定高 400px 捲動。
  • 不採星等：改為單純「過 / 不過」（移除 star 相關程式與樣式）。

踩雷紀錄（捲動）

結果頁一度無法捲動：.results-body 是 flex column，子元素被壓縮塞進容器高、加上 .results-detail 的 overflow:hidden 裁掉內容 → 永不溢出。解法：結果容器絕對定位填滿 .app-content 繞過 flex 高度鏈，並 .results-body > * { flex-shrink:0 }；明細另設 400px 內捲。（測試務必硬重整避免舊 CSS 快取。）

2b 免費版練習次數限制 待討論

現況

練習設定的題數選項是 5 / 10 / 15（practice.js buildQuizCountBtns），但沒有任何依方案（free / Pro）的限制。訂閱頁對比表寫「單字練習 免費 15 題 / Pro 無限」，目前未落實——免費用戶一樣能無限次練習。

要釐清的問題

  • 限制單位：是「每次練習最多 15 題」、還是「每日練習 N 次」、或「每日累計題數上限」？
  • 額度用完後：直接擋下並導去升級（paywall / openPaywall），還是僅提示？
  • 題數選項是否依方案：免費只到 15、Pro 解鎖更多／無上限？
  • 次數如何重置（每日 00:00？）與 demo 如何模擬（比照錄音的 todayUsedMin / maxFreeMin）。

可參考的現有機制

錄音已有「今日免費時間用完 → paywall」流程（startRecording 內 !isPro && todayUsedMin >= maxFreeMin）。練習次數限制可比照：加 pracUsedCount / maxFreePrac，用完在進入練習前導向 openPaywall()（paywallContext='limit'）。

待決定
  • 限制單位與數值（次／題／日）。
  • 用完的 UX（硬擋 vs 提示）。
