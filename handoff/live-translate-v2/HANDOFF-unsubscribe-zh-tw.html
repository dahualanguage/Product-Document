CatchUP Demo v3 (zh-tw)｜訂閱方案 + 管理訂單「整合為單一頁」+ 退訂問卷
已實作 · 可打包交付

i 概述

「訂閱方案」與「管理訂單」整合成單一「訂閱與帳單」頁，依訂閱狀態切換：

  • 免費：方案比較表 + $18/月 + 「立即訂閱」。
  • Pro：目前方案卡 + 付款紀錄（多筆可展開/收合） + 「取消訂閱」入口。

退訂：取消訂閱 → 退訂原因問卷（可複選 + 其他填字） → 確認頁（列出將失去項目 + 輕挽留） → 降回免費版。

全部做在 demo HTML 內（inline JS）+ 共用 styles/v3.css，未動 js/v3/* 等共用邏輯檔。

→ 流程

Profile「訂閱與帳單」 openPaywall()
  ├─ 免費 → 「立即訂閱」 demoUpgrade() → 同頁刷新為 Pro
  └─ Pro → 付款紀錄(可開合) + 「取消訂閱」 openUnsub()
      └─ 退訂問卷(可複選) goUnsubConfirm()
         ├─ confirmUnsub() → 降回免費 → 回訂閱與帳單頁
         └─ keepPro() → 保留 → 回訂閱與帳單頁(Pro)
導航情境 paywallContext：'billing'（個人設定進入，header 返回）／'limit'（今日免費時間用完，保留「暫時不用」回錄音頁）。升級／退訂／保留後皆回同頁刷新。

1 畫面（screens）

ID說明
screen-paywall訂閱與帳單整合頁（免費／Pro 切換）。內含 #paywall-price、#paywall-active、#paywall-cta、#paywall-billing（Pro 才顯示：付款紀錄 #order-list + 取消訂閱）。
screen-unsub退訂原因問卷（可複選 + #unsub-other 其他填字；選了才可繼續）。
screen-unsub-confirm確認退訂（列「你將失去」：無限翻譯次數、無限次練習單字複習 + 確認/保留）。

入口：Profile（screen-profile）「帳號」區 → 「訂閱與帳單」onclick="openPaywall()"。原獨立的 screen-orders 已移除。

2 函式（inline JS）

函式作用
openPaywall()開訂閱與帳單頁，依 isPro 切換版面 + 設 paywallContext='billing' + 返回導航。
demoUpgrade()升級為 Pro；billing 情境停留同頁刷新，limit 情境回上一頁。
closePaywall()「暫時不用」→ 回 previousScreen（僅 limit 情境顯示此鈕）。
renderBillingHistory() / billingRowHTML() / toggleBilling()付款紀錄渲染；超過 BILLING_COLLAPSE_AFTER(2) 筆即收合，附展開/收合。
openUnsub()開退訂問卷，重建原因選項，返回 openPaywall。
buildUnsubReasons() / updateUnsubSelected()渲染複選原因 + 其他填字；控制「繼續退訂」啟用狀態。
goUnsubConfirm()進確認頁。
confirmUnsub()設 isPro=false、更新方案徽章、toast，回訂閱與帳單頁（免費）。
keepPro()挽留：toast + 回訂閱與帳單頁（Pro）。

狀態變數

isPro、isLoggedIn、previousScreen、paywallContext、billingRecords[]、BILLING_COLLAPSE_AFTER、billingExpanded、unsubReasonsData[]、unsubSelected[]

3 檔案

檔案內容
demo-new-v3-zh-tw.html三個 screen 的 HTML + 上述所有 inline JS。
styles/v3.css退訂樣式（.unsub-*）、付款紀錄開合（.billing-toggle）。

星等版 demo-new-v3-zh-tw-star.html 的退訂/帳單完全相同（僅練習呈現不同）。

串接後端時：isPro 換成訂閱狀態 API；billingRecords 換成付款紀錄 API；confirmUnsub 內呼叫取消訂閱 API（實務通常「期末生效」）；退訂原因（unsubSelected）送分析/後端。
