Settings 那一步套到各 practice

八張卡的 Settings 那一步收在同一頁：R11 的工具列 ＋ 視窗預覽。工具列的格子只放這張卡真的有的設定（照 origin/develop @ 599dd4cb 查）；畫布照學生端的主欄抄。控制項可以點，畫布跟著變。 前兩張（Content Mirroring、Vocabulary Mirroring）是 v3／v4 定案的參考實作，照原樣搬過來當對照；Vocabulary Quiz 沒有顯示／音檔設定，它的「設定」是 v6 定案的 Question Types 一扇窗（HOW MANY／HOW TO PICK ＋ 矩陣）；Comprehension Quiz 只有題目清單，沒有可畫的面板。

Content Mirroring v3 定案（R11 的出處）。現行 step-two-mirroring.js：共用 AudioModeToggleCard、Pinyin／Translation／Translation first 三個下拉、AudioSettingsPanel、MaxAttemptsField。

畫布照學生端 practice-content-list.js 的主欄：標題列＋齒輪、PRACTICE SENTENCE 卡、一次一句。Play 鈕字面寫著會怎麼播——Translation first 開著時先播英文（卡先變藍的 Meaning，再變綠的 Listen & Repeat；message-list.js 的 getSentenceCardMeta）。Audio only 時 Pinyin／Translation 交給學生，卡上只留 Listen carefully and repeat the sentence。 Choice by student 幾個就是齒輪面板裡幾列：拼音預設開、翻譯與 Translation first 預設關（index.js 的初始值）。完整四步見 v3 proposal。

Vocabulary Mirroring v4 定案。現行 vocabulary-step-three-section.js（!isMultipleChoice）：Pinyin／Translation／Image 三個下拉（印 enum）、AudioSettingsPanel、MaxAttemptsField。沒有 Audio Mode、沒有 Translation first。

畫布照學生端 vocabulary/index.js 的主欄：齒輪（settings-panel.js）＋ 一疊卡（card-stack.js）。一個字＝三張卡（字 → 例句 1 → 例句 2，parsePracticeCards()），VOCABULARY 卡左半是圖、右半拼音在字上面、翻譯在下面（關掉時位置留著）；EXAMPLE 卡沒有圖。Image 只有 Shown／Hidden，沒有 Choice by student。 前提仍是 v4 spec §5 的 E1：學生端現在根本沒讀這三個值，畫的是「如果讀了會長這樣」。完整四步見 v4 proposal。

Open-ended Questions 現行 qa-step-two-section.js：Audio Mode 卡、Pinyin 下拉（印 enum）、Speed／Voice、Guide phrase language 下拉。沒有 Translation、沒有 Max tries。

畫布照 qa/components/MessageList.js：灰底題目泡泡（拼音 caption 在上、題目粗體、右邊 30px 圓形播放鈕）；Audio only 時泡泡先藏起來，學生點眼睛才看到（Tap the eye to reveal the question）。 Guide phrase language 決定播放前導語用哪種語言（StartPracticeButton.js 的四句，另一種語言留作 caption）。學生端齒輪（settings-panel.js）在 QA 永遠有 Speed；Pinyin 那列只在 Choice by student 時有。

Sentence Scramble 現行 sentence-scramble-preview.js（settings 模式）：Pinyin 下拉（印 enum）、Speed／Voice、Attempts per sentence。沒有 Translation、沒有 Audio Mode。

畫布照 sentence-scramble/index.js：白卡上一句粉色提示 ＋ 0 / 3 tries；Listen to sentence；虛線答案區（每個詞一個空格、標點固定）；下方詞池（白底磁磚，拼音 11px 在字上面）；右下 Check。 Max tries 就是右上角那個 / 3。學生端齒輪：Pinyin 與 Speed 各只在 Choice by student 時有。

Sentence Response ／ Sentence Building 兩張共用 follow-pattern-settings.js：自己畫的 Audio Mode 開關、Pinyin／Translation 下拉（印 enum）、Speed／Voice、Attempts per question。 預覽哪一張：

畫布照 follow-pattern/question-card.js（主色 #14B8A6）：提示句 ＋ 0 / 3 tries；題目框（逐詞拼音在上、字 18px、翻譯斜體）；Response 多一個 Use this pattern to answer: 的句型框，句型裡要填的那一塊淡綠反白（follow-pattern-chunks.js 的 highlight）；Audio only 時題目框只寫 Listen to the question。 這裡的 Practice mode 用的是 Follow Pattern 自己的 audioMode——行為是「題目不顯示文字」，跟 Mirroring 共用卡是同一件事，可以換成同一格。

Vocabulary Quiz v6 定案。它的 Settings 步沒有顯示／音檔設定（vocabulary-step-three-section.js 在 isMultipleChoice 時只有 Practice Name ＋ 題目清單），所以這裡畫的是第二步 Question Types 那一扇窗：工具列決定「幾題、怎麼挑」，畫布就是矩陣。

同一套 R11 語彙：工具列 HOW MANY（Use all ｜ Fewer than that ＋ 題數）‖ HOW TO PICK（Random ｜ Must cover，縮了才出現）‖ 右邊唯讀的算式。矩陣照題幹分四組（Chinese／Image／Translation／Audio），欄只寫答案側；Use all 時鎖住、一格一顆綠點；Fewer 時變勾選，欄頭＝整欄、每列主勾＝整字；Must cover 時欄頭就是「必考」的勾（實心），必考先逐字填滿，不夠題數的差額自動隨機補、check_box藍勾標出來。八張題型說明卡在 v6 是獨立一段放在這扇窗上面，這裡不重畫——見 v6 proposal。
