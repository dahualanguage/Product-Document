Settings 那一步套到各 practice

R11 的工具列 ＋ 視窗預覽，套到還沒做的三張卡。工具列的格子只放這張卡真的有的設定（照 origin/develop @ 599dd4cb 查）；畫布照學生端的主欄抄。控制項可以點，畫布跟著變。 Vocabulary Quiz 與 Comprehension Quiz 的 Settings 沒有顯示／音檔設定（只有 Practice name ＋ 題目清單），R11 不適用，不在這裡。

Open-ended Questions 現行 qa-step-two-section.js：Audio Mode 卡、Pinyin 下拉（印 enum）、Speed／Voice、Guide phrase language 下拉。沒有 Translation、沒有 Max tries。

畫布照 qa/components/MessageList.js：灰底題目泡泡（拼音 caption 在上、題目粗體、右邊 30px 圓形播放鈕）；Audio only 時泡泡先藏起來，學生點眼睛才看到（Tap the eye to reveal the question）。 Guide phrase language 決定播放前導語用哪種語言（StartPracticeButton.js 的四句，另一種語言留作 caption）。學生端齒輪（settings-panel.js）在 QA 永遠有 Speed；Pinyin 那列只在 Choice by student 時有。

Sentence Scramble 現行 sentence-scramble-preview.js（settings 模式）：Pinyin 下拉（印 enum）、Speed／Voice、Attempts per sentence。沒有 Translation、沒有 Audio Mode。

畫布照 sentence-scramble/index.js：白卡上一句粉色提示 ＋ 0 / 3 tries；Listen to sentence；虛線答案區（每個詞一個空格、標點固定）；下方詞池（白底磁磚，拼音 11px 在字上面）；右下 Check。 Max tries 就是右上角那個 / 3。學生端齒輪：Pinyin 與 Speed 各只在 Choice by student 時有。

Sentence Response ／ Sentence Building 兩張共用 follow-pattern-settings.js：自己畫的 Audio Mode 開關、Pinyin／Translation 下拉（印 enum）、Speed／Voice、Attempts per question。 預覽哪一張：

畫布照 follow-pattern/question-card.js（主色 #14B8A6）：提示句 ＋ 0 / 3 tries；題目框（逐詞拼音在上、字 18px、翻譯斜體）；Response 多一個 Use this pattern to answer: 的句型框，句型裡要填的那一塊淡綠反白（follow-pattern-chunks.js 的 highlight）；Audio only 時題目框只寫 Listen to the question。 這裡的 Practice mode 用的是 Follow Pattern 自己的 audioMode——行為是「題目不顯示文字」，跟 Mirroring 共用卡是同一件事，可以換成同一格。
