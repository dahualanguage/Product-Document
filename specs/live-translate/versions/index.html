v2 — Bottom Nav, Word Bank & Quiz
2026-05-28
Bottom nav 架構、單字庫管理、測驗系統、月曆紀錄頁。
  • Bottom Nav: M3 Navigation Bar（錄音 / 單字庫 / 測驗 / 紀錄）取代 Drawer
  • 單字庫: 卡片/清單雙模式、排序（最新↓/最舊↓）、翻譯預設顯示、播放按鈕
  • 測驗: 拼寫/跟讀 checkbox、出題範圍（隨機/常錯/新加入）、題數 5/10/15、單字預覽頁
  • 練習: 拼寫輸入 + 跟讀錄音、progress bar、結果頁
  • 紀錄: 月曆檢視模式、點選日期顯示當日 session
  • 錄音流程: 簡化為 錄音→總結、單字可移除、再次收音延續上次 transcript
  • 重點色: 青藍 #00B8D9 用於 tap-to-save 單字高亮

v1 — Core Flow & History
2026-05-25
Complete mobile demo with recording flow, word saving, session history, and word card detail.
  • Recording: Language selector (EN→ZH/ES), live waveform, tap-to-save words, pause/stop
  • Review mode: Stopped state with word count, review transcript before ending
  • Summary: Session stats, saved word list, rename & notes
  • History: Date-grouped session list, tap to view detail
  • Session detail: Tabs (逐字稿 / 儲存單字) with independent translation toggles
  • Word cards: POS badge, pronunciation, definition, example with highlight; image & multi-POS support
