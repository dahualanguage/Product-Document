AI Live Translate

Mobile-first app — real-time English speech transcription, instant translation, tap-to-save vocabulary, and built-in practice modes.

Live Translate Status: v2 Demo Complete Updated: 2026-05-28 Open Demo v2 →

1 Overview

Goal: Enable anyone to listen to English in any context — a lecture, a meeting, a video — and build vocabulary in the moment, then practice those words immediately.
🎧
錄音

Real-time English speech-to-text with instant translation.

📚
單字庫

Browse, sort, and manage saved vocabulary across sessions.

✏️
測驗

Spelling and mirroring practice with customizable quiz settings.

📅
紀錄

Calendar-based session history with full transcript review.

2 Navigation

App uses a M3 Navigation Bar (bottom tab bar) with 4 tabs. The top bar shows the DAHUA AI logo on first-level screens, and switches to a back-arrow + title bar on sub-screens.

TabIconRoot ScreenSub-screens
錄音micStart (language selector + waveform + start button)Recording → Summary
單字庫bookmarksWord Bank (card/list view)—
測驗quizQuiz setup (type + source + count)Preview → Practice → Results
紀錄historyCalendar viewSession detail (transcript + words)
Nav visibility: Bottom nav is hidden during active recording and practice sessions. It reappears when the user returns to a root screen or summary.

3.1 Start Screen

  • Language selector: EN → ZH / ES, dropdown picker
  • Idle waveform: Decorative bar visualization
  • Start button: Full-width green gradient, border-radius: 14px

3.2 Live Translation

  • Popup hint: "點擊單字即可保存" — dark popup, auto-fades after 2.5s
  • Transcript blocks: English (bold) + translation below (left border). Last block highlighted green ("incoming")
  • Tap-to-save: Tapping a recognized word saves it instantly. Saved words show #00B8D9 (cyan) text color. Toast confirms save
  • Live waveform strip: Animated bars at bottom during recording
  • Controls: Pause button + "結束翻譯" stop button (red gradient)
  • Timer: Red badge in top bar showing elapsed time

3.3 Summary

  • Stats: Duration + saved word count
  • Fields: Session name (auto-filled with date/time) + notes textarea
  • Saved words list: Each row shows English + translation + ✕ remove button
  • 再次收音: Returns to recording screen with existing transcript preserved (does not reset)
  • 完成: Ends session, returns to start screen

4 單字庫 (Word Bank)

Aggregates all unique words across all history sessions. Translation is always visible (no toggle).

4.1 Card / List View

Segmented control in top-right switches between two modes:

ModeContent per word
Card (view_agenda)Full word card: word, translation, pronunciation, POS badge, definition, example, image (if available)
List (view_list)Compact row: 🔊 play button + English word + translation

4.2 Sort & Filter

  • Filter chips: 全部 | 最常保存
  • Sort: 最新↓ / 最舊↓ (toggles on tap, inline with filters)
  • Stats: "詞彙數：10"

4.3 Word Card Detail

Unified card structure for single-POS and multi-POS words:

ElementDescription
HeaderEnglish word (17px, 600) + translation (14px, 500, green) + pronunciation (11px, italic) + 🔊 play button
POS Section (×N)POS badge (11px, 500) + optional image (200×200, rounded 8px) + definition (15px, 500, #0f172a) + translation line (13px, #94a3b8) + example (13px, italic, #0f172a, highlight word 700 #059669)
Multi-POSSame structure repeated per sense, separated by border

5 測驗 (Quiz)

5.1 Setup Screen

Three setting cards stacked vertically:

SettingOptionsBehavior
練習類型☑ 拼寫 ☐ 跟讀Checkbox — can select both. At least one required
出題範圍隨機 | 常錯 | 新加入Determines which words are auto-selected in preview
題數5 | 10 | 15Options disabled if word bank has fewer words

5.2 Preview Screen

  • Title: "即將測驗 N 個單字" + subtitle "在測驗開始前請先複習這些單字"
  • Checkbox word list (English + translation) — user can manually add/remove words
  • "開始測驗" button at bottom

5.3 Spelling Practice

  • Progress bar at top (green gradient)
  • Question counter: 1 / 5
  • Badge: 拼寫
  • Hint area: Chinese translation (24px, 600) + POS + pronunciation + English definition (green left-border card)
  • Input field: center-aligned, letter-spaced
  • Correct → green border + "✓ 正確！" → "下一題" button
  • Wrong → red border + show correct answer → auto-advance after 1s

5.4 Mirroring (跟讀) Practice

  • Badge: 跟讀
  • English word displayed large (28px, 600) + pronunciation
  • 🔊 Play button: green circle, plays reference audio
  • 🎤 Record button: red, pulsing animation while recording
  • Stop → "✓ 錄音完成！" → auto-advance after 1s

5.5 Results Screen

  • Trophy icon (green #10b981)
  • "練習完成！" + score (N / total 答對)
  • "返回" button → navigates back to quiz setup or session detail (depending on entry point)
Entry points: Quiz can be started from the 測驗 tab (pick words freely) or from a Session Detail page (auto-selects that session's words).

6 紀錄 (History)

6.1 Calendar View

  • Month calendar: Grid with ◀ ▶ month navigation
  • Green dot: Dates with recordings show a small green dot below the number
  • Selected date: Light green rounded square (#ecfdf5, border-radius: 10px)
  • Day sessions: Below calendar, shows "5/28 — 2 筆紀錄" + session cards for that date
  • Empty state: "這天沒有錄音紀錄"

6.2 Session Detail

Tapping a session card navigates to a detail page with two tabs:

TabContent
逐字稿Full transcript (EN + translation). Translation toggle (on/off). Saved words highlighted in #00B8D9
儲存單字Word cards for all saved words in this session. Translation toggle independent from transcript tab
