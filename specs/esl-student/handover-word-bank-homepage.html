Dismissible notification at the top of the content area. Collapses smoothly on close.

Primary tabs filter the word list. "By Subject" and "By Source" reveal a second row of sub-filter pills.

By SubjectFilter by subject fieldScience, Math, History, Geography (with counts)
By SourceFilter by source fieldLive Classroom, Practice, Teacher Added (with counts)
LearningFilter by state = learningNone
MasteredFilter by state = masteredNone

Sub-pill Spec

  • Default: 11px weight 600, #475569, border #e2e8f0

Scrollable list of all words matching the active filter. Clicking a word updates the detail card.

List Spec

  • Container: same card style as detail card
  • Header: "Word List" + count badge (#f1f5f9 bg, #64748b)
  • Item height: auto, padding 9px 10px
  • Item border: bottom 1px solid #f1f5f9

  • Hover state: #f8fafc bg
  • Word text: 13px weight 600, #0f172a

Pagination

  • Per page: 8 items
  • Page buttons: 28×28px, radius 6px
  • Active page: #10b981 bg, white text
  • Arrow buttons: ‹ / ›

3 Data Model

3.1 Word Object

Each word in the word bank needs the following fields:

FieldTypeDescriptionExample
wordstringEnglish word"hypothesis"
translationstringChinese translation"假說"
definitionstringEnglish definition"A proposed explanation..."
definitionTranslationstringChinese definition"基於有限證據..."
examplestringExample sentence (with target word highlighted)"We need to test our <mark>hypothesis</mark>..."
exampleTranslationstringChinese example translation"在得出任何結論之前..."
partOfSpeechstringPOS tag"noun"
typestringWord type classification"Academic"
sourceenumWhere word came from"live" | "practice" | "teacher"
subjectstringSubject category"Science"
stateenumMastery state"learning" | "mastered"

3.2 Source Values

ValueDisplay LabelMeaning
liveLive ClassroomCaptured during a live class session
practicePracticeAdded from practice errors
teacherTeacher AddedManually assigned by teacher

3.3 Smart Sets (Computed)

SetLogic
Top 10 Most MissedBottom 10 by accuracy score, include average accuracy %
10 Recently AddedLatest 10 by createdAt timestamp
Weekly Review FocusSpaced-repetition algorithm picks (due for review)
Not Yet TestedWords with 0 practice attempts

6 States & Edge Cases

ScenarioExpected Behavior
Empty word bank (new student)Show empty state illustration with "Start learning to build your word bank" message
No words match filterShow "No words found" in list area, detail card stays showing last selected word or empty
All words masteredNotice banner: "All words mastered!" with celebratory message
No mastered words yetHide notice banner entirely
Translation unavailableTranslate toggle still works — blank/empty fields if no translation data
Long word or definitionDefinition in list truncated with ellipsis at 280px; detail card shows full text
Single page of resultsHide pagination controls entirely
Collapsed upper + filter changeUpper section stays collapsed; only word list updates

7 Suggested API Endpoints

Note: These are suggested endpoints based on the UI requirements. Backend team should finalize the actual API contract.
EndpointMethodPurpose
GET /api/student/word-bankGETFetch all words with filters (subject, source, state), pagination
GET /api/student/word-bank/setsGETFetch smart set definitions (counts, avg accuracy)
GET /api/student/word-bank/statsGETFetch mastery stats for notice banner (newly mastered count)
GET /api/student/word-bank/:idGETFetch full word detail (if not included in list response)

Query Parameters for Word List

ParamTypeDescription

sourcestringFilter by source (live, practice, teacher)

pagenumberPage number (1-based)
perPagenumberItems per page (default: 8)
