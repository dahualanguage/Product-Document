# Colors

## Primary Brand (shared)

| Hex | Usage |
|-----|-------|
| `#10b981` | Active sidebar, correct stat color |
| `#059669` | Logo text, hover states |
| `#ecfdf5` | Sidebar active bg |
| `#22C55E` | Check button, Start button, correct input border |
| `#77ED8B` | Progress bar gradient start |

## Input States

| State | Border | Background | Text |
|-------|--------|-----------|------|
| Default | `2px solid #e2e8f0` | `#fff` | `#0f172a` |
