ESL Student — UX Copy

Component copy sheet and change log for the ESL Student v11 interface.

Design System — 5.2 ESL Student v11 Updated: April 2026
How to use
  1. Review Mode (top right) — Reviewers click to edit the Caroline / Hope / Dara columns directly. Changes auto-save to Google Drive.
  2. Edit Mode (top right) — PM clicks to see ✓ buttons on reviewer suggestions. Click ✓ to adopt a suggestion into the Text column.
  3. Save Approved — After adopting, click the green button at the bottom to save finalized copy to Drive.
  4. Export — Download all changes as Readable / JSON / Markdown for sharing.
How to read this sheet — Each page has an annotated wireframe with numbered markers. The table below maps each number to the exact text on screen. Includes static HTML, JS-generated, hover tooltips, and modal content.
