ESL Teacher — Version History

UI iteration log for the ESL Teacher dashboard. Each version captures design progress across all screens.

Latest
v5 — KPI Tracker, Language Barrier & Practice Insights
2026-04-09
Consolidated dashboard covering configurable monitoring modules, practice tracking panels, and classroom word insights.
  • KPI Tracker: Human-readable rule tags (e.g. 5 times / 7d), shadcn-style Recurring vs One-time schedule, edit modal with inline Delete, "N days left" countdown with yellow/red warnings, 6 WIDA presets seeded with default rules
  • Language Barrier Watches: Configurable Add Watch flow (Name / Metric / Time Window / Target) replacing the fixed 6-group grid; metrics choice between word tap count and translation hover seconds; 7/14/30/Custom windows; 3-column responsive grid
  • Shared Watch Target picker: Reusable groups + individual students picker used by both KPI Tracker and Language Barrier modals — KPIs can target specific students, not only WIDA groups
  • Insight Inbox panel: 5 most recent sessions with unread indicators (yellow bg + green View button), session metadata, word count badges, unified View button style
  • Practice Frequency & Duration: Goal-based trackers with configurable targets, group + practice-type filters, top 3 worst students highlighted, row-1 height synced across Insight Inbox / Frequency / Duration
  • Most Tapped Words in Class & Most Missed Words in Practice: 50:50 side-by-side layout, Top N (5/10/15/20/30) + period (3/7/14/30d) selectors, 30-word demo data, 10-row fixed height with scroll, subject / practice-type tags per word
  • Visual hierarchy: Light-gray container tint (#f1f5f9) on KPI Tracker and dash-card shells with white inner blocks for clear module separation
  • Navigation: All sidebar Dashboard links across Session Insights / Students / Insight Inbox point to v5 dashboard

v4 — Streamlined Dashboard & Insight Inbox
2026-03-27
Streamlined Dashboard & Insight Inbox — removed assignment features, focused on student practice data and word tap insights.
  • Dashboard layout: 2-column grid — Insight Inbox (50%) + Student Practice (50%), Most Tapped Words (full-width)
  • Student Practice: Renamed from "Words Mastered", shows practice times per student with expandable per-student bars per group
  • Most Tapped Words: Removed Related Forms column — table shows #, Word, Appeared in, Tapped only
  • Removed from Dashboard: My Students module, Assignments Due Soon, sidebar Assignments & Settings
  • Students page: Dedicated page — Name, WIDA Level (1–6), Native Language, Subjects, editable Group dropdown with toast notification
  • Insight Inbox: Simplified — removed Create Assignment, View Transcript, Level column; scroll isolation between panels
  • Cross-page nav: Dashboard ↔ Students ↔ Insights all linked via sidebar

v3
v3 — Create Assignment + Connected Flow
2026-03-26
Multi-step Create Assignment wizard connected to Insight Inbox. Teachers can assign practice from session tapped words directly. Flow Diagram Section D added.
  • Create Assignment (4-step wizard): Select Words → Practice Type → Assign Students → Confirm & Send
  • Step 1 — Select Words: 2-column word chips with Save Rate, tap count, WIDA/ELPAC/CEFR level tags
  • Step 2 — Practice Type: 4 type cards (Practice All, Spelling, Multiple Choice, Mirroring) with student-side SVG icons
  • Step 3 — Assign Students: Current session class students, WIDA level filter (All / Level 2 / 3 / 4), Select All toggle
  • Step 4 — Confirm: Summary card with source, type, students, due date, word list
  • Insight Inbox updates: View Transcript button, removed progress bar from session cards, removed duplicate subject tag
  • Connected flow: Insight Inbox → Create Assignment linked via URL params (?session=), Back to Inbox on success
  • Dynamic sessions: All 6 sessions (sci-cell, math-frac, hist-wall, etc.) work with correct words & class data
  • Flow Diagram: Section D added — Teacher Assignment Flow (Insight Inbox → Student Practice)

Simple Ver — Student-only Word Tap
2026-03-25
Stripped-down Insight Inbox focusing purely on student tap data — no AI suggestions. Linked with Dashboard via sidebar navigation.
  • Word table columns: Word, Level (WIDA / ELPAC / CEFR tags), Save Rate, Tapped
  • Save Rate vs Tapped: Save Rate = % of students who saved (max once); Tapped = total tap count (repeatable)
  • Level tags: Each word shows 3 proficiency tags — W (WIDA 1–6), E (ELPAC 1–4), CEFR (A1–C2)
  • Tooltips: Column headers have rich info tooltips with glow effect and tag legend
  • Session cards: Class name + teacher / date / time slot + word count bar
  • Navigation: Dashboard ↔ Insights linked via sidebar

v2 — High-fidelity Dashboard
2026-03-20
High-fidelity dashboard with 2-column grid layout, interactive filters, and overlapping bar chart. Sidebar matches ESL Student app shell (88px, PNG logo).
  • My Students: 3 WIDA-level group cards (1–2, 3–4, 5–6) with student counts, total count + monthly growth in header
  • Insight Inbox: AI-analyzed session keywords with unread/read state, word count badges, View buttons
  • Words Mastered: Dual dropdown filters (Group + Period 3/7/14/30 days), overlapping horizontal bar chart (green current vs yellow prev.), fixed x-axis scale with dot markers, "vs prev. period" checkbox toggle
  • Assignments Due Soon: Urgency tags (Overdue/Today/Date), inline progress bars, completion percentage
  • Pending Actions: Smart alerts — unassigned words, active student word banks

v1 — Low-fidelity Wireframes
2026-03-19
Initial wireframe design embedded in the product spec. 7 screens covering the full ESL Teacher workflow — from dashboard overview to assignment creation.
  • App shell: Topbar (DAHUA AI + ESL Teacher mode badge) + sidebar nav (Dashboard, Students, Insights, Assignments, Settings)
  • Dashboard (A): Insight Inbox preview, My Groups cards, Recent Sessions list, Pending Actions
  • Students (B): Group filter tabs, student table with Name/Group/Level/Word Bank/Last Session
  • Session Insights (C): Split-pane — AI Content Analysis (keywords, summary) + Student Behavior (save rate bars)
  • Create Assignment (D): 4-step stepper (Source → Type → Target → Preview), word chips, assignment type cards
  • Insight Inbox (E): Chronological session list with unread/read state, word count badges
  • Student Detail (F): Profile info, ESL group, word bank summary, progress chart
  • Assignment List (G): Status tracking (Draft/Active/Completed), group/student assignment targets
