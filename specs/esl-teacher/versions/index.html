v8 — Tag Design System & Create New Class
2026-05-22
Unified tag token system, reduced green overuse, gradient primary buttons, and new Create New Class flow.
  • Tag token: All tags unified to 11px / 600 / border-radius 20px / no border
  • Tag types: Semantic colored (WIDA level, subject topic, countdown warning) · Neutral gray (grade, subject, tracker metadata) · Plain text (trend, metric target)
  • Green reduction: grade-tag, subject-tag, tracker-list-tag, tt-subject → neutral gray; kpi-rule-tag.metric → plain gray text; barrier-trend → colored text only (no background)
  • Subject topic tags: Science / Math / History / Social Studies unified to gray (no per-subject color)
  • Trend labels: "Improving / Declining" removed pill background — green / red text only, consistent with number color
  • Gradient buttons: All primary buttons use linear-gradient(135deg, #10b981, #059669) with shadow + lift on hover
  • Button radius: Pill buttons (border-radius 20px) replaced with consistent 10px across all CTAs
  • Create New Class: "Start new class" now opens a Create Class modal (Class Name, Subject, Grade, Level, Assign Teacher) — Create Class button activates only when required fields filled — on submit, transitions to Share Code modal with class code

v5 — Unified Tracker System, KPI Tracker & Language Barrier
2026-04-13
Unified Tracker configuration model — teacher sets up one set of trackers that drive all three dashboard panels (KPI Tracker, Language Barrier, Most Tapped Words).
  • Unified Tracker model: Merged separate KPI rules and Language Barrier trackers into a single trackers array. Each tracker defines Name, Metric, Target, Cycle, Start/End, and Students — all three panels consume the same config
  • Expanded metrics: 5 metric options — Number of Practices, Duration (mins), Mastered Words, Word Tap Count, Translation Hover (s)
  • Manage Trackers modal: Click + New Tracker (now in page header) to open a tracker list with edit/delete per item, plus Add New Tracker button at bottom
  • Tracker Target picker: Filter-based student selector with Native Language (Chinese/Spanish) + WIDA Level (1–6) dropdowns, Select All, custom checkboxes with green checkmark icon
  • KPI Tracker: Reads from unified trackers — expandable progress bars per student, countdown tags, color-coded met/below/far status. No in-panel edit icons
  • Language Barrier: Passively reads tracker student lists — shows avg taps/student per tracker group. Independent 3/7/14/30 day filter in panel header for time comparison. No in-panel edit icons
  • Most Tapped Words: Tracker group filter dropdown added — switch between All Students or specific tracker groups. Taps scale proportionally to group size
  • Student data: 18 students across WIDA 1–6, each with taps & hover time-series data (7/14/30 day windows) in addition to times/mins/words
  • + New Tracker in page header: Button moved from KPI Tracker header to Dashboard page-head row, serving as the single entry point for all tracker configuration

v3 — Create Assignment + Connected Flow
2026-03-26
Multi-step Create Assignment wizard connected to Insight Inbox. Teachers can assign practice from session tapped words directly. Flow Diagram Section D added.
  • Create Assignment (4-step wizard): Select Words → Practice Type → Assign Students → Confirm & Send
  • Step 1 — Select Words: 2-column word chips with Save Rate, tap count, WIDA/ELPAC/CEFR level tags
  • Step 2 — Practice Type: 4 type cards (Practice All, Spelling, Multiple Choice, Mirroring) with student-side SVG icons
  • Step 3 — Assign Students: Current session class students, WIDA level filter (All / Level 2 / 3 / 4), Select All toggle
  • Step 4 — Confirm: Summary card with source, type, students, due date, word list
  • Insight Inbox updates: View Transcript button, removed progress bar from session cards, removed duplicate subject tag
  • Connected flow: Insight Inbox → Create Assignment linked via URL params (?session=), Back to Inbox on success
  • Dynamic sessions: All 6 sessions (sci-cell, math-frac, hist-wall, etc.) work with correct words & class data
  • Flow Diagram: Section D added — Teacher Assignment Flow (Insight Inbox → Student Practice)

Simple Ver — Student-only Word Tap

Stripped-down Insight Inbox focusing purely on student tap data — no AI suggestions. Linked with Dashboard via sidebar navigation.
  • Word table columns: Word, Level (WIDA / ELPAC / CEFR tags), Save Rate, Tapped
