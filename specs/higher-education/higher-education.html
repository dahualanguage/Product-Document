Higher Education

Self-directed transcription & academic vocabulary support for university-level students — with Mini Player floating subtitle bar.

ESL Module — 3.7 Status: Concept Audience: University / Advanced Updated: May 2026

1 Use Case & Context

Advanced learners — university students or high-grade secondary students — encounter dense academic vocabulary in lectures, seminars, and subject-matter videos. Unlike the K–12 ESL student who works inside a teacher-managed class, this user operates independently: they open a laptop, start recording, and want real-time transcription with word-level support without any instructor setup.

Target User

University student or advanced learner taking content-heavy lectures (science, law, business, etc.) with high academic vocabulary density. No teacher or admin in the loop.

Core Problem

Academic lectures move fast. Students miss or misunderstand specialist terms they haven't encountered before. They need real-time support without disrupting the flow of listening.

2 Session Creation (Student-Initiated)

There is no teacher to create or schedule a session. The student starts directly from My Class. There are two paths to start a new session:

2.1 Direct Start (No Subject)

StepActionDescription
1Open My ClassStudent lands on their class home page.
2Tap "Start new class"Opens mic permission check and begins recording. No subject assigned yet.
3Grant Microphone PermissionBrowser permission prompt on first use. State is remembered for subsequent sessions.
4Recording BeginsLive transcript appears in real time. Student can click any word to save it.
5End Class → Assign Subject (optional)After ending, student can file the session into a Subject group — or leave it unclassified.

2.2 From Subject Group

StepActionDescription
1Open My ClassStudent sees list of Subject groups.
2Tap a Subject group (e.g. History)Opens the subject folder — shows past class sessions in that subject.
3Tap "+ New Class"Starts a new session. Subject is automatically assigned to this group.
4Recording BeginsSame as direct start. Session is pre-filed under the chosen subject.

3 Full Transcription View (Active Tab)

When the student is focused on the app, they see the standard live transcription interface — same rendering pipeline as Live Classroom (3.6), but without teacher controls.

4 Mini Player

This is the defining feature of 3.7. When the student switches to another browser tab or application — e.g. taking notes in Notion, or looking up a concept — the transcription session does not stop. The tab collapses into a persistent floating subtitle bar overlaid on the screen.

How is Mini Player implemented technically?
Option A — Picture-in-Picture API (native browser, video element required). Option B — always-on-top browser popup window. Option C — Electron / desktop app wrapper that can draw over other windows. Each has trade-offs for web portability and permission complexity.
Where does the Mini Player appear on screen?
Default position (bottom-center? top-right?), whether it is draggable, and whether its position persists across sessions.
Platform constraint: A standard browser tab cannot render content on top of other tabs or native apps. Mini Player requires either the Picture-in-Picture API, a separate popup window, or a desktop app wrapper. This needs a technical feasibility decision before design can finalise.

6 My Class

My Class is the student's home page. It shows all Subject groups (folders) and provides entry points to start a new session.

ElementDescription
Start new classTop-level CTA. Starts a session with no subject pre-assigned. Student can assign a subject after class ends.
Subject group listAll subject folders the student has created (e.g. History, Biology). Each shows a preview of how many sessions are inside.
+ New SubjectCreates a new subject folder. Student provides a name.

6.1 Subject Group (Folder View)

Tapping a Subject group opens the folder and shows all sessions inside it.

ElementDescription
Session listPast sessions in this subject, sorted by date. Shows session name, date, duration, and saved word count.
+ New ClassStarts a new session pre-filed under this subject. No additional subject selection needed.
Subject assignment is flexible: Sessions started from the top-level "Start new class" are unclassified by default. The student can drag or assign them to a Subject group at any time — during review or immediately after class ends.

6.2 Session Detail

Tapping a session opens a detail view:

  • Full transcript — scrollable, all saved words still tappable
  • Saved words from this session — quick-access list
  • Subject assignment — move session to a different subject group if needed

8 Open Questions

  1. Subject naming — Is the subject name free text (student types anything), or selected from a preset list? Does it affect anything beyond the folder label?
  2. Unclassified sessions — Where do sessions without a subject appear on My Class? A separate "Uncategorised" section, or always at the top?
  3. Mini Player implementation — PiP API / popup window / desktop wrapper? Needs technical feasibility decision before design finalises.
  4. Mini Player position — Default screen position, draggability, and whether position persists across sessions.
  5. Account requirement — Does the student need an account, or can sessions be anonymous / guest?
