新版 Planning mode 搶先試用：選出最符合您需求的版本Try the new Planning mode first: pick the version that fits you best

為了改善大家在使用大話平台時遇到的不便，我們正在規劃新功能 Planning mode，希望能讓您更快速地建立練習。目前我們準備了兩個版本，還沒有最後定案。To fix the frustrations teachers run into on the Dahua platform, we're planning a new feature, Planning mode, to help you create practices faster. We've prepared two versions and haven't made a final decision.

想麻煩您兩個版本都試用一次，再選出符合您需求的版本，並和我們分享原因。答案沒有對錯，您的每一個想法都對我們非常重要，衷心感謝您撥空協助！We'd be grateful if you could try both, pick the version that fits your needs, and tell us why. There are no wrong answers; every thought you share matters to us. Thank you so much for your time!

四分鐘影片：為什麼做、兩個版本差在哪、請您怎麼做。下面是同樣內容的文字版。Four-minute video: why we're doing this, how the two versions differ, and what we'd like you to do. The text version follows below.

我們想解決的三個痛點The three pain points we want to fix
1
要先弄懂 Project、Practice、Teaching Point、Question Bank 這幾個概念，才用得順平台，學習成本高。You have to understand Project, Practice, Teaching Point and Question Bank before the platform feels usable. That is a lot to learn.
2
建一個練習要走四步；同一份課文建兩個練習，每個決定都要重做一次，很花時間。Creating one practice takes four steps; two practices from the same text means making every decision twice. It takes too long.
3
第一次使用的老師不知道該從哪裡開始。First-time teachers don't know where to start.

新的 Planning mode 是建立練習的新入口，把「做什麼、用哪份內容、給誰」三個決定收在一起問；兩個版本都在解這三個痛點，差別在怎麼問。The new Planning mode is a new entry point for creating practices: it gathers the three decisions (what to make, which content, for whom) in one place. Both versions tackle these pain points; they differ in how they ask.

Demo 1

助手欄＋建立頁Assistant + create page

主畫面就是現在的建立頁，左邊多一個助手。問您三題之後，陪您一步一步把四步做完、派出去。您還是看著熟悉的頁面做決定。The main screen is today's create page with an assistant beside it. After three questions it walks you through the four steps and the assignment. You decide on the familiar page.

Demo 2

對話決定 → 草稿卡Conversation → drafts

主畫面是一段對話。先在對話裡把教學點、句子決定好，直接生出草稿；看過學生會拿到的畫面後，在對話裡一次指派。建立頁只在要改的時候才出現。The main screen is a conversation. You decide teaching points and sentences in the chat, drafts are generated right away; you preview what students get, then assign in one step. The create page only appears when you want to edit.

兩個版本做的是同一件事，差別在「您在哪裡做決定」：看著建立頁做，還是在對話裡先說完。Both versions do the same job; the difference is where you make decisions: on the create page, or in the conversation first.

為什麼兩個情境Why two scenarios　情境一看「從頭建練習」的整條路，情境二只看「指派」這一步。兩個版本在這兩段的做法差最多，所以每個版本都請您各做一次，才比得出來。Scenario 1 covers the whole path of building practices; scenario 2 looks only at assigning. The two versions differ most in these two parts, so please do both scenarios in each version.
怎麼進行How it works　先在 Demo 1 做情境一、情境二，再換到 Demo 2 把同樣兩個情境再做一次。每個情境做完回來填三題；最後選一個、說為什麼。Do scenarios 1 and 2 in Demo 1, then switch to Demo 2 and do the same two scenarios again. Answer three questions after each; then pick one and tell us why.
完成碼Completion code　每個情境做完，原型畫面最下面會有一串像 D1-S1-4m12s-B1-H2 的碼，按 Copy 貼回這裡。沒做完就填「沒做完」。After each scenario the prototype shows a code like D1-S1-4m12s-B1-H2 at the bottom. Press Copy and paste it here. If you did not finish, write "did not finish".
