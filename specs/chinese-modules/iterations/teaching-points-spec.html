教學點方框（Teaching points）

老師建立練習時，第一步用來勾「要練哪些教學點」的黃色方框。六種練習用同一個樣子，請工程一起改齊。

共用元件2026-11-05狀態：設計定案，等工程排程；兩題等後端回程式碼基準：dahua-dash origin/develop @ bcdf3d33原型：Sentence 四種 · Vocabulary 兩種

原型只示範第一步的方框。第二個專案的教學點在第二步沒有對應的假資料，不用理會。

2 範圍

六種練習的第一步都要老師勾教學點，畫面上是同一個黃色方框。但產品裡三個步驟檔各做各的：加點的地方、用字、底色、自己加的點怎麼取消，都不一樣（逐條見第 4 節的「現在」欄）。這一版把六種改成同一個樣子、同一套用字和行為；加教學點的地方跟著專案走；例句跟教學點放在一起看。

3 設計規格

下面五小節是定案的樣子與行為。用詞和程式裡的名字對照在第 7 節。

3.1 方框的樣子

每個選到的專案一個方框，方框之間隔 12px。由上往下：標頭 → 教學點按鈕 → 加點列 → 自訂輸入列。

Sentence Scramble 第一步：上面是「要幾句」那一行（已經沒有 1–2 each），下面是教學點方框，加點列收著開原型 ↗

區塊規則
底色六種一律黃 #FFF8E7（PRACTICE_TYPE_COLUMNS.VOCABULARY.wash）。外框圓角 14px、內距 3px、面板之間 3px，照現在的 ContentFrame
標頭專案名 ＋ 小字 Teaching points ＋ 右邊 已勾/總數。沒有全選框
教學點按鈕樣式照現在的（高 34px、圓角 10px、勾了綠框淡綠底）。勾＝會進練習；再點一下＝取消勾，按鈕留在原位
按鈕上的標Added：老師在這一步自己加進來的點。Grammar：型別是 GRAMMAR 的點，專案裡的或自己加的都掛。兩個可以同時出現，順序是字、Added、Grammar。按鈕上不印其他型別
預設勾選選進來的專案，它的教學點預設全勾。把專案從 Projects 選單取消，它的點一起退出
沒有教學點的專案第一個白色面板寫 No teaching points. You can add some below.
全選框拿掉之後，要全部取消就一顆一顆點。

3.2 加教學點

每個方框底下有自己的一塊：加點列（從這個專案的課文挑詞）和自訂輸入列（自己打）。加進來的點都歸這個方框的專案。

加點列展開：跟底下的詞池連成一塊淺綠；起床、早饭、睡觉已經是教學點，打勾不能按開原型 ↗

區塊規則
加點列一整列是一顆按鈕，文字 Add teaching points from project，箭頭在最右邊。預設收起，每個專案各自開合。上面沒有小標、右邊沒有數字
詞池加點列展開後接在它正下方，兩者連成一塊。還不是教學點的詞：前面一個 ＋，按一下就加進這個專案的按鈕列最後、已勾、掛 Added，型別是預設的 Word / Vocabulary。已經是教學點的詞：綠框綠字打勾，不能按。專案沒有課文時寫 This project has no text to pull words from.
自訂輸入列輸入欄（placeholder Custom teaching point）＋ 型別下拉（預設 Word / Vocabulary）＋ Add。六種都有型別下拉。按 Enter 也能加（中文輸入法選字的 Enter 不算，照 add-words-panel.js 現在的判斷）；空的時候 Add 不能按。加的點出現在按鈕列最後、已勾、掛 Added；型別選 Grammar / Structure 的再掛 Grammar
型別選項照各練習現在的清單：Vocabulary Quiz 只列詞類，其他五種列全部八個
重複加的字已經在這個專案的按鈕列裡：不新增，只把那顆勾起來
取消自己加的點跟專案的點一樣，點一下是取消勾，按鈕留著、可以再勾回來。不是移除

3.3 例句清單

只有 Sentence Scramble、Sentence Cloze、Sentence Building。老師選了 Example sentences from teaching points 那張卡才出現；沒選的時候方框就是 3.1 的樣子。

選了例句：原本那一排按鈕收掉，例句清單在方框裡，左欄就是教學點按鈕；加點的區塊在清單下面開原型 ↗

區塊規則
位置在每個專案的方框裡，取代原本放按鈕的那個白色面板。加點的面板在它下面
標題列Example sentences　Untick any you don’t want · N of M picked。N、M 只算這個專案
左欄就是教學點按鈕本身，勾或取消在這裡做。最小寬 128px，跟右邊的例句隔 12px
勾著、有例句的點右邊列它的例句，一句一列，樣式照現在（勾選框、中文、拼音、翻譯）
勾著、沒有例句的點右邊寫 No examples · will be generated（例如老師自己加的點）
沒勾的點左邊按鈕留著，右邊空白
其他提示清單以外的提示（哪些點沒有例句、還會生成幾句）照 Sentence 練習的交接包，這裡不改
原則：同一個教學點在畫面上只出現一次。選了例句，它就在例句清單的左欄；沒選例句，它就在按鈕那一排。

3.4 Vocabulary 兩種

Vocabulary Mirroring 和 Vocabulary Quiz 用同一個方框，沒有例句清單。用字跟 Sentence 一樣是 teaching points，不再寫 words。

Vocabulary Mirroring 第一步，加點列展開。語法點「一……就」掛 Grammar開原型 ↗
