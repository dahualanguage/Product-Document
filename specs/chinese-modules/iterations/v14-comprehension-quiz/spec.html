v14 — Comprehension Quiz（基準）

Comprehension Quiz（?type=MULTIPLE_CHOICE）的建立流程是三步：Question Bank → Edit & Preview → Assign Practice。第一步跟 Open-ended Questions 共用題庫選單（use-question-bank-step.js、article-preview-section.js），第二步是這張卡自己的（mc-step-two-section.js ＋ 殼裡的 ExamModeCard），第三步八種共用。為 Planning mode 四張灰卡而開，只有基準、沒有提案。

② 設定項與選項值

這條流程沒有 Pinyin／Translation／Audio Mode／Speed／Voice／Max attempts。buildCreatePracticeInput 對 MC 只帶 questionsBankSk；第二步 Save 只多 practiceName、examMode、timeLimit、mcQuestions。
控制項值存到哪、學生端有沒有讀
Select a Question Bank老師所有題庫，最新在前；只算 true_or_false ＋ multi_choice（countMCQuestions），QA 題不算questionsBankSk；學生端不讀題庫、讀複製進 practice 的 mcQuestions
Practice Name預設＝題庫名；空白時 Save 前沒有擋（validateStepTwo 對 MC 跳過：activeStep === 1 && !isMC）practiceName；學生端頂欄與完成頁顯示
Test Mode（開關）預設關examMode；有讀：開了才有計時 chip、時間到自動交卷
Time limit（Slider）1–60 分，預設＝建議值 max(1, round(題數×30/60))（10 題 → 5 分）；關掉 Test Mode 存 nulltimeLimit；有讀：timeLimit×60 秒倒數
題目卡 ✕／拖曳刪題、換順序；不能改題目文字與選項（要去題庫）mcQuestions（順序即學生作答順序）

老師設定學生端
examMode／timeLimit有讀。計時從進頁面起算（sessionStorage exam_start_{assignmentSk}），刷新不重置；時間到 isTimedOut：選項不能點、自動 handleSubmit({ force:true })，沒答的不算分。
mcQuestions 順序有讀。照老師第二步排的順序出題，沒有亂序。
拼音／翻譯／音檔老師端沒得設；學生自己按（課文面板的兩個 switch ＋ TTS；題目翻譯只有 comprehension 有，按了才 generateMCQuestionTranslation）。用量有埋 Amplitude MC_FEATURE_USED。

④ 查到的問題、要問工程的

1 · 沒有任何顯示／音檔設定

共用設定畫廊的 S3／S4／S6／S7 在這張卡都不適用；只有 Practice Name（S1）、Test Mode。要不要讓老師決定「學生能不能開拼音／翻譯」，是這張卡的第一個問題。

2 · 名稱在第一步被設、第二步才看到

選題庫就把 practiceName 設成題庫名（S1 同一題）。

3 · 第一步按 Next 就建 practice，之後題庫鎖住

要換題庫只能整份重來；EDIT 模式第一步根本進不去（mcEditMinStep = 1）。

4 · Edit in Question Bank 會離開流程

改字要去題庫頁，回來走 EDIT；流程裡只能刪、排序。Planning 的 iframe 嵌入時這顆鈕會把人帶走。

5 · 第二步預設全部展開

10 題全開、每題四個選項，拖曳換序要拖過整張長卡；第一步的 Preview 已經列過一次題目，第二步再列一次。

6 · 刪光了 Save 還能按

mcHasNoQuestions 只擋第一步；第二步全刪 → InlineEmpty，Save 照送空的 mcQuestions。

7 · 學生端沒有開始頁、計時從進頁面就跑

Test Mode 的學生沒機會準備；選了就鎖、不能改答案，跟一般「考試」的預期不同（考試通常交卷才判）。

8 · Test Mode 文案

卡片叫 Test Mode、欄位叫 examMode、Planning 叫考試模式；學生端只有一顆計時 chip，沒說這是考試。
