v6 — 優化 Practice-Vocabulary Quiz

Vocabulary Quiz 的建立流程是四步：Vocabulary → Question Types → Settings → Assign Practice。第一步跟 Vocabulary Mirroring 是同一支檔案、第四步八種共用， 這張卡自己的是中間兩步。§2–§5 是現況與學生端，§6 是查到的問題，§7 是待決事項。登記完等使用者說要改哪裡，還沒有提案。

2026-09-17 分岔自 v4（第一步、第四步沿用） 程式碼基準 origin/develop @ 3e821fa4 狀態：已登記

1 這一版的範圍

New Practice → Vocabulary Quiz（Choose Practice Type 的第四張卡；?type=VOCABULARY&subType=MULTIPLE_CHOICE）這條建立流程。 跟 Vocabulary Mirroring 共用 step-one-vocabulary.js（差別只有 isVocabMC 時不出現 Read Sentences Only），共用 vocabulary-step-three-section.js（但走 isMultipleChoice 分支，內容完全不同），共用 Assign。

// practice-stepper-config.js @ 3e821fa4 VOCABULARY_MC_STEPS = ['Vocabulary', 'Question Types', 'Settings', 'Assign Practice'] getStepsForType(VOCABULARY, isVocabMC = true) → 上面這四步（Mirroring 是三步） // practice-unified-view.js isVocabMC = isVocab && isMultipleChoiceType(vocabSubType) mcTypesStepIdx = 1 // 第一步按 Next 建 practice 時 vocabSubType 先不送（null）—— // Multiple Choice 在第二步按 Next 時才連同 mcQuestionTypeSelection 一起 patch，生成只跑一次

已經定下來、可以直接套的（見 共用改動 spec）：S1 名稱搬第一步、S2 第一步的元件（v4 的第一步做完它就有）、S8 Assign、S9 頁腳與捲動。 不適用的：S3–S7——它的 Settings 步沒有顯示／音檔設定。

沿用 v4 的：假資料（我的一天，六個字 ＋ 一個文法點）、第一步的基準複刻、Assign 的基準複刻。

2 現況：四步走完

步畫面上有什麼出處
1 Vocabulary跟 Vocabulary Mirroring 一模一樣：Autocomplete 多選專案、Teaching Points Preview、Load Content → 生詞卡（編輯／隱藏／選圖／Add Vocab）。少了 Read Sentences Only（showReadModes={!isVocabMC}）。Next 在 practice 存在前是灰的。step-one-vocabulary.js、vocabulary-display-section.js
2 Question Types標題 Choose Question Types；Paper 裡 Question Configuration ＋ 右上 chip N questions · M words；兩顆模式鈕 Random／Advanced。Random：一個 Number of questions 數字欄（上限 字數 × 8）。Advanced：八張題型卡各一顆 Switch ＋ 逐字矩陣（列＝字、欄＝題型，表頭每欄一顆「Apply to every word」、每列一顆三態）。一個都沒選 → warning Alert。vocabulary-mc-question-types-step.js
3 Settings只有 Practice Name ＋ Divider Multiple Choice Questions Preview (N questions) ＋ 一句 Drag a question onto another to reorder, or remove it with the delete button. ＋ 題目卡清單 ＋ 虛線 Add Question。沒有 Display Settings、Audio Settings、Max attempts（全在 !isMultipleChoice 裡）。頁腳這一步叫 Save。vocabulary-step-three-section.js（isMultipleChoice 分支）、mc-questions-preview.js
4 Assign Practice八種共用。step-three.js、assign-practice.js

生成時機：第一步 Next 建 practice（帶 projectConfigSks，subType 先不送）；第二步 Next 才 patch generateVocaUpdatedArticleArrayType = MULTIPLE_CHOICE ＋ mcQuestionTypeSelection，後端照選擇生題。再經過第二步不重生，除非選擇變了——重生會丟掉第三步做過的刪除與排序（程式碼註解自己講的）。

3 第二步 Question Types

3.1 八種題型（MC_QUESTION_TYPE_LABELS，順序照選擇矩陣）

VOCAB_MC_EN_TO_CNTranslation → ChinesePick the correct Chinese meaningtext
VOCAB_MC_EN_TO_PINYINTranslation → PinyinPick the correct pinyin✓text
VOCAB_MC_AUDIO_TO_ENAudio → TranslationListen, pick correct Englishaudio

VOCAB_MC_AUDIO_TO_PINYINAudio → Pinyin（599dd4cb 之後新增）Listen, pick correct pinyin✓audio

「Advanced」是三個答案為拼音的題型的標記（琥珀小 chip），畫面上沒有解釋它代表什麼。圖片題型在圖還沒好的字上 disabled，tooltip No image yet — generated once available（isImageReadyForMc：imageStatus === 'ready' 或有 customImage）。 pattern 類 teaching point（GRAMMAR／PHRASE／OTHER）在生成前就被丟掉（isPatternVocabEntry），矩陣裡不會出現。

3.2 兩種模式

  • Random：只給一個總數，buildRandomDistribution() 把題型隨機分到每個字；老師看不到分配結果。上限 字數 × 8。
  • Advanced：題型卡的 Switch 切整欄，矩陣切單格；兩者寫的是同一份 selection（切回 Random 會用總數重算一份）。

4 第三步 Settings

每張題目卡（mc-questions-preview.js，editable）：拖曳把手、Q1 primary chip、題型 chip、題幹（文字題幹直接印字；圖／音題幹印來源字）、右邊 Raffle 鈕（outlined，swap 圖示）與紅色刪除鈕（最後一題不能刪：At least one question is required）；下方左邊圖片 120×90 或 64px 播放鈕，右邊選項兩欄，正解綠框 ＋ ✓。

  • Raffle：把這一題換成同一個字的另一種文字題幹題型（TEXT_STEM_TYPES 裡隨機挑，排除目前的）。圖／音題幹的題型不在候選裡。
  • Add Question：對話框選一個字 → A random question type will be generated，同樣只在文字題幹題型裡隨機。
  • 刪除、排序、Raffle、Add 都是前端改 mcQuestions 陣列再 persistMcQuestions；按 Save 時整份送出。

跟 Comprehension Quiz 的差別：Comprehension Quiz 在同一位置多一張 ExamModeCard（Test mode ＋ 時限 1–60 分鐘），Vocabulary Quiz 沒有；學生端也不傳 examMode。

5 學生端：一題一張卡

出處 src/sections/assignments/content/mc/。Vocabulary Quiz 與 Comprehension Quiz 用同一個 MCPractice，只差資料來源（adaptVocabMCQuestions(practice.multipleChoiceQuestions)）與沒有 examMode。

// vocab-mc.js · adaptVocabMCQuestions() { questionType, stem: { type: 'text'|'image'|'audio', value | s3Path }, question: stem.type==='text' ? stem.value : '', choice: { A: …, B: …, C: …, D: … }, answer: [correctAnswer] } // index.js · QuestionScreen 頂欄：進度條（#77ED8B→#22C55E）＋ 「current / total」；examMode 才有計時 chip 卡片：題型 chip（MC_TYPE_COLORS[questionType] || '#666' —— 八種 vocab 題型都不在 MC_TYPE_COLORS 裡，chip 是灰的） 題幹框（grey.500 6% 底）：文字 h5 600 置中／圖片 maxHeight 200 置中／音檔 64px 播放鈕 ＋ 'Click to play audio' 選項單欄直排：32px 圓形字母 ＋ 選項文字；選了立刻回饋（正解綠框 ✓、選錯紅框 ✕），不能改 底部：Back（outlined）／ Next（contained，選了才亮）／ 最後一題 Finish（success） 完成頁：分數圓環 /100、Correct／Wrong／Total 三格、Question Review 逐題（Q 標紅綠、題型 chip、你的答案 vs 正解）

「Translate」開關只在 TRANSLATABLE_MC_CATEGORY（Comprehension 的題）出現，vocab 題沒有。老師端第三步畫的是選項兩欄、正解打勾；學生看到的是單欄、沒有正解。

6 查到的問題

每一條都在程式碼裡看得到。編號只是編號。跟 v4 重複的只註明。

1 · 第一步整套是 v4 的問題

名稱在第一步被設、第三步才看到（S1）；Load Content 與灰 Next；生成後專案鎖死。v4 提案已經解掉，這裡直接套——第一步是同一支檔案。

2 · 那一步叫 Settings，裡面沒有設定

isMultipleChoice 時只有 Practice Name ＋ 題目清單 ＋ Add Question。Comprehension Quiz 同樣內容的那一步叫 Edit & Preview。名字講的是 Mirroring 才有的東西（R10）。

3 · Random 模式看不到結果

只給一個數字，題型怎麼分到哪個字是後端／buildRandomDistribution 決定的，畫面上沒有任何回饋；要看只能切到 Advanced（切過去它會用總數重算一份，不是「看」）。老師到第三步才第一次看到題目。

4 · 逐字矩陣是 8 欄 × N 列

字一多就是一面勾勾牆；欄標題是八個「A → B」，讀起來都像。圖片題型在圖還沒好的格子 disabled、tooltip 說 generated once available——是排隊等圖好了再生，還是靜默略過，要問（E1）。

5 · 「Advanced」沒有說明

三個拼音題型掛琥珀 chip Advanced，卡片上沒講它代表「答案是拼音、比較難」。R9。

6 · 回到第二步改選擇會丟掉第三步的工

程式碼註解：Regenerating discards the questions that exist, including any the teacher deleted or reordered on the Settings step。畫面上沒有任何提醒（R9）。

7 · Raffle 與 Add Question 都是「隨機」

Raffle 只在文字題幹的題型裡隨機換一種、老師不能指定；Add Question 也是選一個字然後隨機一種。「Raffle」這個字在講機制（抽籤），不是老師關心的事（R7）。

8 · 老師端的題目卡跟學生端不是同一張

老師端選項兩欄、正解打勾、題幹文字在標頭；學生端選項單欄直排、題幹在框裡置中、沒有正解。跟 v4 問題 2 同一類（R6）。

9 · 學生端題型 chip 是灰的

MC_TYPE_COLORS 只有 true_or_false 與 multi_choice，八種 vocab 題型都落到 '#666'；老師端第二步每種題型倒是各有顏色（TYPE_META）。是不是漏了，要問（E5）。學生端的事，這一版不改，記下來。

10 · 兩個小的

Random 的 Number of questions 預設值從程式碼看不出來（buildInitialSelection 在 shared helper 裡，基準檔先放 12，待查）。第三步的 Add Question 對話框標題與按鈕都寫 Add，內容說 random question type will be generated——同一件事兩個動詞（R10）。

7 待決事項

分兩類：要使用者決定的（設計方向），和只有工程答得出來的。

要決定的

#題目為什麼要先決定
D1這一版要改哪裡？照流程，登記完等使用者說。問題 2–8 是這張卡自己的，1 是 v4 已解的。
D2第一步直接套 v4 提案？同一支檔案；套了就有多選、A + B、勾 teaching point、Add words、Next 生成、回頭不鎖。唯一要看的是 Quiz 不需要例句／圖片的部分要不要在第一步就少畫。
D3第二步與第三步要不要合成一步？第二步選題型、第三步看題目——中間隔一次生成。合成「選了就看到」要後端能逐題生（E2）；不合的話至少第三步該改名。
D4Random 模式留不留？它是「不想想」的捷徑，但結果看不到。留的話要顯示分配；不留的話 Advanced 就是唯一模式，矩陣得變好用。

要問工程的

#題目狀態
E1圖片題型在圖還沒好時勾了，是排隊生還是略過？tooltip 寫 generated once available；決定矩陣那些格子要不要能勾。
E2題目能不能逐題生／單題重生？現在是第二步 Next 一次生全部；Raffle／Add 是前端用 buildMcQuestion() 在本地拼的（文字題幹才拼得出來）。決定 D3 與 Raffle 能不能指定題型。
E3重生時能不能保留第三步的刪除與排序？問題 6。
E4Vocabulary Quiz 要不要 Test mode？Comprehension Quiz 有（ExamModeCard：時限 1–60 分鐘），Vocabulary Quiz 沒有。是刻意還是沒做到。
E5學生端題型 chip 顏色 #666 是不是漏了？問題 9。一行的事，不必等定稿。
E6Random 的預設題數與分配規則是什麼？問題 10；buildRandomDistribution 在 shared helper，登記時沒讀。
