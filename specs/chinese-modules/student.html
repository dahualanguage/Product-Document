1 My Assignments

The student home for assigned work. /student/practice

  • Tabs: Mandatory · Optional
  • Groups: Ready to submit · Today · Later (Completed moves to history)
  • Type filter: All · Q&A · Mirroring · Vocabulary · Multiple Choice
  • Per-card: type, due/expiry label, status (Not started / In progress / Ready to submit), action (Start / Continue / Submit)
Due-date urgency colours. Ready to submit · Today / Overdue · Tomorrow · This week · Later / no due date

2 Practice sessions (by type)

Q&A

Shows a prompt from project content; student records a spoken answer; playback + score/feedback.

Mirroring

Karaoke-style sentence with native audio; student repeats; pronunciation score per sentence.

Vocabulary

Three sub-modes — Mirroring (listen & speak), Mixed, Multiple Choice (word→meaning).

Multiple Choice

Question + (for reading) project content; True/False or 4-option; immediate feedback; result page with score & per-question review.

3 Word Game

Gamified, Duolingo-style vocabulary mastery. /student/word-bank-game New Summer Program gated

  • Modes: New Challenge (new words) · Smart Review (low-mastery words)
  • Session: 1–3 words; ~4 min/word is an estimate only (not enforced)
  • 5 exercises / word (fixed order): Vocab Mirroring · Sentence Mirroring · Fill-in-blank · Translation quiz · Pinyin quiz
  • Stars: 1 per exercise (max 5 / word) — Mirroring needs pronunciation rating ≥ 4/5; quizzes need a first-try correct answer (no retry)
  • Mastery: 1–4 stars = Learned · 5 stars = Mastered (backend authoritative)
  • Ends when: all words' exercises are done — there is no hearts / time-out game-over
Not in the game (yet): hearts, coins/shop, time limit and difficulty are not implemented (some enums exist but aren't wired). The sidebar ⭐ / ❤️ are account-level stats, separate from the game.
