3 · 還沒開始 —— 沒有東西可以附著

沒有 run 的時候沒有附著列，框回到現在的樣子：一個空白框加一句範例。差別只在於——現在你一眼就分得出這兩種狀態，以前分不出來。

為什麼是「附著」，不是換一句 placeholder 就好

換 placeholder 也能講「你可以改這個」，但 placeholder 一打字就消失。而老師最需要那個資訊的時刻，正好就是打字的那一刻 —— 打到一半停下來想「這樣會不會把剛才那些設定沖掉」。所以它必須是一個留在框裡的元素，不是提示文字。

附著標籤也順手解決另一件事：對話越長，越看不出自己在做什麼。捲到下面之後，上面那句「Using 食物 · creating Content Mirroring」早就滾出畫面了。框在最底下、永遠看得見，正好是放這個資訊的地方。

而且一旦框說了「我附著在這個 run 上」，就必須給一個脫離的出口 —— 那顆安靜的「改開新的 ✕」。沒有它，這個設計只講了一半。
