Word Game — Design System

The playful, storybook-quest visual language for the student Word Game dashboard: rounded display type, a fresh brand-green palette with candy accents, chunky tactile components, and springy micro-motion.

Student · Chinese Modules Fonts: Fredoka + Nunito Live ref: student-redesign.html Updated: July 2026

1 Aesthetic Direction

A kids' Chinese-learning game. The mood is storybook adventure — warm, tactile, rewarding. Three rules keep it coherent:

PrincipleWhat it means
Rounded & chunkyOne 20px radius for every card & panel (controls 14px, chips 8px), thick inner borders, and a pressed inset 0 -3px 0 bottom on buttons for a soft 3D "toy" feel.
Green-first, candy accentsBrand green dominates; gold (stars), coral (hearts/urgent) and purple (bonus) appear only as meaningful accents — never decoration.
Frosted over sceneContent sits on translucent white panels (rgba(255,255,255,.95) + blur) floating above the illustrated landscape.

9 Iconography & Mascot

The prototype uses emoji as lightweight icons (⏰ 💬 🎤 📚 ✅ ✦ ⭐ ❤️ 🔥 🎁). The brand mascot Douhua (豆花), a tabby cat, appears as animated GIFs — waving in the coach strip, reading for Smart Review, winking for New Challenge.

Production note: emoji render differently per-OS. For the real app, swap to a consistent icon set (e.g. a rounded custom set or Phosphor/Lucide) while keeping the mascot GIFs from /assets/game/moscot/.

10 Layout & App Shell

Floating sidebar + rounded stage, on a soft green-blue app background. The Word Game dashboard is tasks-first: a wider left column for deadlines, a right rail for free practice + optional quests.
