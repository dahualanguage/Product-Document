1 Context & goals

1.1 · Why

Today a student only practises what a teacher assigns. There's no self-directed daily habit and no place to own vocabulary between assignments. This round adds a self-study loop: a daily challenge that cycles the four practice types, a Chinese word bank as its content home, and a gaming layer that motivates coming back.

The three pieces work together. Daily Challenge is the engine · Word Bank is the content source · Gaming is the motivation layer. Design them as one system, ship them incrementally.

1.2 · Goals

  • Daily habit — students practise on their own most days (measure: daily-active + streak length)
  • Vocabulary retention — words a student meets get revisited to mastery (measure: mastery growth)
  • Motivation — the gaming layer makes practice feel rewarding (measure: return rate, sessions/week)

1.3 · Non-goals / constraints

  • Does not replace teacher-assigned practice — it sits alongside My Assignments
  • Reuses existing practice engines (Q&A / Mirroring / Vocabulary / MC) — no new practice type this round
  • Chinese product only (a Chinese Word Bank already exists inside the Word Game — preset; this round is about its source, not building it from scratch)

2.1 · Self-directed practice — Daily Challenge New status: proposed

What: A daily, self-initiated challenge that runs one round through the four practice types — Q&A → Mirroring → Vocabulary → Multiple Choice — then rewards the student.

Why: Builds a daily habit and lets students practise without waiting to be assigned.

Where it lives: on the Gaming hub page shown above — the ring is the daily loop; each node opens an existing practice session.

Content source: auto-selected from — Word Bank words? recent assigned projects? a curated pool? (see §4)

Key states: available today · in progress (step 1–4) · completed today (locked until tomorrow) · streak count.

Rewards: stars / coins / streak++ on completion (defined in 2.3).

Open questions: fixed 4 steps or configurable? · retry same day? · what if a type has no content available?

2.2 · Chinese Word Bank exists (in Word Game) preset today

Reality check: a Chinese Word Bank already exists inside the Word Game — a preset fixed list (~507 words), each word showing 1–5 star mastery (Learned / All Words / Mastered tabs). Word Game draws its practice words from it. This is separate from the ESL /student/word-bank (ESL-only).

What (design): a student's Chinese vocabulary home — word + pinyin + translation + audio, with mastery — and the content source for Daily Challenge & Word Game.

Key design question — where do the words come from?

OptionSourceTrade-off
A · Preset todayFixed official word list (current behaviour)Simplest, already works; but disconnected from what the student is actually assigned
B · DynamicWords from the student's assigned content (projects / practices), teacher-set, or student-addedMatches the learner's real path; needs a data source + dedupe / levelling
C · HybridPreset official list + words auto-collected from assignmentsMost complete, most complex

Also open: does Daily Challenge draw from this same bank? · does Word Bank get its own page, or stay inside Word Game? · keep the existing per-word 1–5★ mastery model?

3 User flows

3.1 · Daily Challenge loop core

Home / sidebar ─▶ Start challenge ─▶ 1 Q&A ─▶ 2 Mirroring ─▶ 3 Vocabulary ─▶ 4 Multiple Choice ─▶ Result ─▶ back (see "today's (content auto-selected) record / speak / answer (score + challenge" card) stars · coins · streak++)
  • Entry — student sees "Today's challenge" (not yet done) with current streak.
  • Round — 4 steps, one per practice type, using existing session UIs; a progress indicator shows 1/4 … 4/4.
  • Result — summary score + rewards earned; streak increments; challenge locks until tomorrow.
  • Edge cases — already done today (show recap + tomorrow countdown) · a type has no content (skip or substitute?) · quit mid-round (resume or lose progress?) · hearts run out

3.2 · Word Bank → practice supporting

Word Bank ─▶ pick word(s) / "review weak" ─▶ practice (mirroring / quiz) ─▶ mastery updates ─▶ back to bank
  • Detail how a student starts practice from the bank, and how mastery feeds Smart Review / Daily Challenge.
