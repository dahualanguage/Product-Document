Build with AI

Conversational AI assistant that guides teachers through content creation, question generation, practice setup, and assignment distribution — all in one flow.
Status: Proposal Version: 0.1 Last Updated: 2026-02-28 Roles: TEACHER / SCHOOL_TEACHER / SCHOOL_ADMIN

1 Problem Statement

1a. Teachers find the platform hard to use

To create a complete lesson that students can practice, a teacher currently needs to navigate 5 separate pages and understand 5 platform-specific concepts:

Current flow (5 pages, 5 concepts): Projects ──> Question Banks ──> Practice List ──> Assignments ──> Assign to Class (create (generate (create Mirroring (create from (select class article) questions) or QA practice) practice) & students) Problem: Teacher must understand every concept and navigate between pages. "I keep jumping back and forth and don't know where to go next."

K-12 teachers want flexibility — they want to customize content, choose question types, set difficulty levels. But the current UI makes them pay for that flexibility by requiring them to learn the platform's internal architecture.

1b. Onboarding friction is being removed

Previously, teachers had to manage student onboarding (invite codes, student self-registration). This is being replaced by a form-based approach where schools provide student emails and names, and the platform boards them directly.

Result: when a teacher first opens the platform, their classes and students are already set up. No onboarding friction.

1c. What this means

The remaining friction is entirely in content creation and distribution.
If we can flatten the 5-page workflow into a single guided conversation, we solve the primary usability problem for K-12 teachers.

2 Feature Goal

2a. One-sentence definition

Build with AI lets a teacher go from "I have a lesson topic" to "my students can start practicing" in a single conversational interface — without needing to understand Projects, Question Banks, Practices, or Assignments as separate concepts.

2b. What the teacher experiences

Build with AI flow (1 page, 0 concepts to learn): Teacher: "I have an article about the Moon Festival, B1 level, make 5 MC questions and a mirroring practice, assign to Class A" AI: "Got it! Here's what I'll do: 1. Use your article about the Moon Festival 2. Adjust to B1 level 3. Generate 5 multiple choice questions 4. Create a Mirroring practice 5. Assign to Class A (18 students) Should I start?" [Yes, go ahead] [Let me adjust] Result: Teacher completes in one conversation what used to take 5 pages.

5b. Intent recognition system

When the teacher types free text instead of clicking a button, the system uses AI to understand their intent and extract parameters.

Intent classification table

IntentDescriptionExtractable Parameters

build_question_bank Teacher wants to generate or create questions questionType (MC/TF/QA), count, linkedProject
setup_practice Teacher wants to create a practice (Mirroring or QA) practiceType (mirroring/qa), linkedProject, linkedQB
assign_to_students Teacher wants to distribute an assignment className, practiceName
view_progress Teacher wants to check student results className, assignmentName, studentName

unclear AI cannot determine intent (confidence < threshold) —

AI confirmation before proceeding

Rule: When the teacher uses free input, the AI must always confirm its understanding before taking any action. Never auto-execute based on NLP alone.

11 Edge Cases & Rules

11a. Error handling

ScenarioAI ResponseAction
AI content generation fails "Sorry, I wasn't able to generate the content. This might be due to a temporary issue." Show [Try Again] and [Enter Content Manually] buttons
OCR extraction fails "I had trouble reading your image. The text might be too blurry or the image too small." Show [Upload Another Image] and [Paste Text Instead] buttons
URL fetch fails "I couldn't access that URL. It might be behind a login or unavailable." Show [Try Another URL] and [Paste Text Instead] buttons
Question generation fails "I wasn't able to generate questions. Let me try again." Show [Try Again] and [Add Questions Manually] buttons
Insufficient credits "You don't have enough credits to generate this content. Each generation uses 5 credits." Show [Top Up Credits] link (navigates to billing page)

11e. Entity created during conversation

Important: Entities are created at specific points in the conversation, not at the end. This means if a teacher abandons the conversation midway, some entities may already exist.

Project is saved at Step 6.6.
Question Bank is saved at Step 7.3 (generation) or 7.4 (manual add).
Practice is saved at Step 8.2.
Assignment is saved at Step 8.4.

Draft resume (Section 9) tracks which entities were already created, so the teacher doesn't create duplicates when resuming.

11f. Content dependency reference

When a teacher creates content through Build with AI, the entities are linked: Project → Question Bank → Practice → Assignment. For detailed documentation on what happens when these are edited or deleted, see Content Dependency & Deletion Behavior.
